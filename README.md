# Hiep Le — The Digital Archive

> A professional minimalist portfolio documenting a 20-year journey through IT evolution.

## 🔗 Live Site
- **Production**: [https://hieple7985.github.io/](https://hieple7985.github.io/)

## 🧭 Overview
- **Framework**: Nuxt 3 (Static Site Generation)
- **Deployment**: GitHub Pages via GitHub Actions
- **Theme**: "Digital Archive" (Minimalist, Animation-driven)
- **Typography**: Archivo (Headings) & Space Grotesk (Body)

## 🛠️ Tech Stack
- Nuxt 3 + Vue 3 + TypeScript
- Tailwind CSS (Typography & Forms plugins)
- Nuxt Content v3 (Markdown-based articles)
- Shiki (Syntax Highlighting)
- Vitest (Testing)

## 🚀 Development

### Installation
```bash
npm install
```

### Local Dev
```bash
npm run dev
```

### Testing
```bash
npm run test
```

### Build & Generate
```bash
npm run generate
```

## 📤 Deployment
The site is automatically deployed to **GitHub Pages** on every push to the `master` branch.
*Workflow location*: `.github/workflows/gh-pages.yml`

*Legacy Note: This project was previously deployed to Firebase and Vercel. Those configurations have been removed to consolidate on GitHub Pages.*
